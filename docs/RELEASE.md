# Source distribution

The package contains the PoT search and training modules, benchmark adapters,
download tools, command-line launchers, tests and documentation.

Installation and benchmark commands are in the README. `docs/METHOD.md`
describes the algorithm and evaluation protocol. Dependencies are listed in
`pyproject.toml` and `requirements-tested.txt`; license information is in
`LICENSE` and `THIRD_PARTY_NOTICES.md`.

Models and datasets are downloaded separately. `SOURCE_MANIFEST.json` records
the SHA-256 hash of each distributed file.
